# Support Ticket Copilot

An AI system that helps support teams handle tickets faster.

## What it will do
- Classify tickets into categories
- Predict ticket priority
- Detect duplicate tickets
- Summarize long ticket threads using an LLM
- Suggest replies using past solved tickets (RAG)

## Tech stack
Python, scikit-learn, Hugging Face, FAISS/ChromaDB, FastAPI, Streamlit, Docker
